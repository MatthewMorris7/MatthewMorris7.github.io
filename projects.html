Personal Portfolio Website

Built entirely from scratch — a professional portfolio site featuring a live AI assistant powered by Claude, secure API integration via a Vercel serverless function, and auto-deployment from GitHub.

This project is a place to drive iterative improvements that I love implementing. I also have the opportunity to try out new tools and further explore AI assistance when it comes to skills I am less familiar with like Java.

HTML / CSS

The entire site is built as a single HTML file with embedded CSS. I used CSS variables, flexbox, and grid to create a responsive layout that works across desktop and mobile — no frameworks needed.

Wrote all markup and styling from scratch, including the floating chat widget, hero layout, activity cards, and responsive breakpoints.
JavaScript

Vanilla JavaScript powers all the interactive elements — the chat widget, typing indicator, API calls, scroll reveal animations, and the tech tab system you're using right now.

Wrote all JS without any libraries or frameworks, exposing functions on the window object so inline HTML handlers work reliably across browsers.
Vercel

Vercel hosts the live site and runs a serverless function (api/chat.js) that securely handles all AI chat requests. The API key is stored as an environment variable — never exposed in the browser or source code.

Configured the project, set up the serverless function, stored secrets as environment variables, and connected auto-deployment from GitHub.
Claude API

Powers the AI chat assistant embedded in the portfolio. All requests are routed through a secure Vercel serverless function that injects the key server-side before forwarding to Claude — keeping credentials safe.

Designed the system prompt with my background context, built the fetch logic, and handled response parsing and error states.
GitHub

The full codebase lives in a GitHub repository. Vercel is connected directly — any time a file is committed to GitHub, Vercel automatically detects the change and redeploys the live site within seconds.

Set up the repository structure, managed all version history, and use GitHub as the single source of truth for all site updates.
